Workflow

How I work

Every build follows the same loop: define the problem tightly, prototype fast, then harden, test and ship something people can actually use.

What I do
Agents, RAG pipelines and security automation that run on local models
How it runs
Python, LangGraph, Ollama and Docker, with every tool call scoped and logged
What I do
Full-stack apps and dashboards, from hackathon prototypes to production
How it runs
Next.js or React with FastAPI and Supabase, deployed on Vercel

See the code →

  1. 00

    Define the problem

    Pin down exactly what the system must decide or do, and what it must never do.

  2. 01

    Data & context

    Collect the sources, policies and documents the model needs, and design the retrieval layer.

  3. 02

    Agent design

    Split the work into focused agents and wire them together as a LangGraph state machine.

  4. 03

    Tooling & guardrails

    Expose tools over MCP, enforce rules of engagement and isolate execution in sandboxed containers.

  5. 04

    Local models

    Run on local LLMs through Ollama or llama.cpp, so data stays on the machine.

  6. 05

    Evaluate

    Unit and end-to-end tests, plus honest notes on what has and hasn't been verified.

  7. 06

    Ship & document

    Containerise, write the README and publish the code so others can run it.

  1. 01

    Brief

    Who uses it, what they need to get done and what success looks like.

  2. 02

    Design

    Mockups for the key screens, matched before any code is written.

  3. 03

    Build

    Typed React or Next.js front end with a FastAPI or Supabase backend.

  4. 04

    AI features

    Chat, RAG, vision or OCR where it actually helps the user.

  5. 05

    Test

    Vitest and Playwright runs, type checks and lint rules on every change.

  6. 06

    Deploy

    Shipped on Vercel or GitHub Pages with a live demo link.

Cybersecurity × AI

Autonomous red teaming

AntiGravity is my fully autonomous, multi-agent Active Directory red team framework. Six LLM agents run on local models, orchestrated through LangGraph with MCP tooling.

  1. 1

    Scope

    Rules of engagement are enforced before any agent is allowed to act.

  2. 2

    Orchestrate

    Six specialised LLM agents coordinate through a LangGraph state machine.

  3. 3

    Isolate

    Every tool runs inside sandboxed containers, separated from the host.

  4. 4

    Stay local

    Models run locally through Ollama, so engagement data never leaves the machine.

Built for authorised security testing and research only.

# Aruneshwaran K · Portfolio

Personal portfolio of **Aruneshwaran K**, B.Tech Artificial Intelligence & Machine Learning student at Bannari Amman Institute of Technology (BIT), Sathyamangalam.

It covers autonomous AI agents, security tooling, hackathon builds and full-stack apps. Each project card opens a live preview or links to its repository.

## Run locally

It's a static site with no build step:

```bash
python3 -m http.server 8080
# open http://127.0.0.1:8080
```

## Stack

- HTML and CSS with the Poppins typeface
- GSAP + ScrollTrigger and Lenis for scroll animation
- Deployed as a static site
